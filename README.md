# Desafio Técnico — Desenvolvimento com Geoprocessamento

## Contexto

A área de geoprocessamento é essencial para empresas que lidam com infraestrutura, saneamento e gestão territorial. Profissionais dessa área precisam dominar a manipulação de dados geoespaciais, visualização em mapas interativos e operações sobre elementos geográficos.

Este desafio tem como objetivo avaliar suas habilidades técnicas no desenvolvimento de aplicações voltadas ao geoprocessamento.

## Descrição Geral

Você deverá desenvolver **do zero** uma aplicação capaz de receber dados geográficos, exibi-los em um mapa interativo e permitir a manipulação desses dados por meio de operações CRUD. Os detalhes completos do desafio estão descritos em [docs/desafio.md](docs/desafio.md).

Um arquivo de exemplo com dados fictícios está disponível na pasta `dados/` para auxiliar nos testes iniciais.
